# 📊 Finance Manage

**Finance Manage** là một ứng dụng Flutter nhằm giúp bạn *quản lý tài chính cá nhân* một cách trực quan và hiệu quả — bao gồm theo dõi thu chi, xem báo cáo theo ngày/tuần/tháng, và quản lý danh mục chi tiêu dễ dàng.

---

## 🚀 Tính năng chính

- 📅 Theo dõi thu nhập và chi tiêu theo thời gian thực
- 🧾 Danh mục chi tiêu/thu nhập tùy chỉnh
- 📊 Báo cáo thống kê trực quan
- 💾 Lưu trữ dữ liệu nội bộ trên thiết bị
- 🎨 Giao diện đẹp & dễ sử dụng

---

## 🛠️ Bắt đầu

### Yêu cầu trước khi cài

Đảm bảo bạn đã cài:

- **Flutter SDK** (>=2.x)
- **Dart**
- Một trình giả lập Android / iOS hoặc thiết bị thực tế

> Nếu bạn mới làm quen với Flutter, tham khảo tài liệu chính thức tại:  
> https://docs.flutter.dev

---

## 📦 Cài đặt

1. Clone repository:
    ```bash
    git clone https://github.com/Minhkl27/finance_manage.git
    ```

2. Di chuyển vào thư mục project:
    ```bash
    cd finance_manage
    ```

3. Cài đặt phụ thuộc:
    ```bash
    flutter pub get
    ```

4. Chạy ứng dụng:
    ```bash
    flutter run
    ```
